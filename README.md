# Inverse Problems Group — website

Single-file static site for GitHub Pages. No build step, no dependencies.

Edit `index.html` directly: replace member names, publications and the `href="#"` placeholders.
The logo is the inline SVG in the hero block — an original mark, not a university mark.

Zenodo DOI: sign in to Zenodo with GitHub, enable the repository under Zenodo -> GitHub,
then create a GitHub Release. Zenodo archives it and mints a citable DOI.
